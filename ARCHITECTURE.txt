│  6. Backend: Process response                                              │
│     ├─ Extract AQI level: 4 (Poor)                                        │
│     ├─ Convert to standard scale: 175                                      │

⚙️ TECHNOLOGY STACK:

Backend:
├─ Framework: Flask 2.3.3 (lightweight Python web framework)
├─ HTTP: CORS enabled for cross-origin requests
├─ Environment: python-dotenv for configuration
└─ API: requests library for external HTTP calls

Frontend:
├─ Graphics: Three.js (WebGL 3D library)
├─ Styling: Custom CSS with dark mode
├─ Communication: Fetch API for REST calls
└─ Runtime: Vanilla JavaScript (ES6+)

External Services:
├─ OpenWeatherMap Air Pollution API (real-time data)
└─ Data Source: Global weather stations network

Deployment:
├─ Development: Flask built-in server (debug=True)
├─ Production: Run on gunicorn/waitress
├─ Port: 5000 (configurable)
└─ Host: 0.0.0.0 (all interfaces)

🔒 Security Considerations:

✓ API Key Security
  ├─ Stored in .env (not in code)
  ├─ Loaded via environment variables
  └─ Never exposed in frontend

✓ Input Validation
  ├─ Type checking (integer for AQI, duration)
  ├─ Range checking (0-500 for AQI, 1-480 for duration)
  └─ Safe defaults if invalid

✓ Error Handling
  ├─ Try-except blocks on API calls
  ├─ Graceful degradation (manual input if API fails)
  └─ No sensitive data in error messages

✓ Data Privacy
  ├─ No user data stored
  ├─ No analytics or tracking
  ├─ No cookies or local storage
  └─ Ephemeral session (browser memory only)
